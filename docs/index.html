Instrument Registry

UNSW Instrument Metadata Registry (TEST SITE)

The UNSW Instrument Metadata Registry provides structured, PIDINST-aligned metadata for research instruments across the University. Persistent identifiers make each instrument easier to find, distinguish, and reference over time, supporting transparent and reproducible research. The registry also enables instruments to be cited consistently in publications, datasets, and other scholarly outputs.
